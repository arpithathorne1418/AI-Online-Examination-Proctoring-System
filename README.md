# AI Online Examination Proctoring System

## Project Description
Our project is an online examination system with student and admin dashboards and examination monitoring features.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Camera and Microphone APIs
- MediaPipe (if integrated)

## Features
- Student Login
- Admin Login
- Student Dashboard
- Admin Dashboard
- Online Examination
- 40 Questions
- 10-Minute Timer
- Camera and Microphone Permission
- Monitoring Alerts

## Project Files
- `index.html` – Complete source code and dashboard
- `presentation/` – Project presentation
